Тестирование доступности хостов
Описание программы

Данная программа предназначена для тестирования доступности веб-хостов с использованием HTTP-запросов.

Программа выполняет заданное количество запросов к указанным URL-адресам и собирает статистику:

количество успешных запросов;
количество неуспешных HTTP-запросов;
количество ошибок соединения;
минимальное время ответа;
максимальное время ответа;
среднее время ответа.

Программа написана на языке Python.

Используемые технологии
Python 3
requests
argparse
re

Модули argparse и re входят в стандартную библиотеку Python и отдельно устанавливать их не требуется.

Сторонняя библиотека проекта:

requests

Запуск программы

Программа поддерживает следующие аргументы командной строки:

Аргумент	Описание
-H, --hosts	URL-адреса через запятую
-C, --count	Количество запросов
-F, --file	Файл со списком URL-адресов
-O, --output	Файл для сохранения результатов

Необходимо указать либо -H, либо -F.

Одновременное использование -H и -F запрещено.

Пример запуска с указанием URL
python main.py -H https://google.com,https://github.com -C 3

В данном случае программа выполнит по 3 HTTP-запроса к каждому указанному хосту.

Пример вывода:

Запуск с использованием файла

Можно указать URL-адреса в отдельном файле.

Пример содержимого hosts.txt:

https://google.com
https://github.com
https://python.org

Запуск программы:

python main.py -F hosts.txt -C 3

Программа прочитает адреса из файла и выполнит указанное количество запросов к каждому из них.

Сохранение результатов

Для сохранения результатов в файл используется аргумент -O:

python main.py -H https://google.com,https://github.com -C 3 -O results.txt

После выполнения программы будет создан файл results.txt.

Пример его содержимого:

РЕЗУЛЬТАТЫ ТЕСТИРОВАНИЯ
==================================================

Host: https://google.com

Success: 3

Failed: 0

Errors: 0

Min: 0.1201

Max: 0.2456

Avg: 0.1678

--------------------------------------------------
Проверка некорректных URL

Программа проверяет формат введённых URL-адресов.

Например, при запуске:

python main.py -H https://google.com,incorrect-url -C 2

будет выведено предупреждение:

Предупреждение: некорректный URL: incorrect-url

После этого будет протестирован только корректный URL.

Обработка ошибок

Программа обрабатывает ошибки при выполнении HTTP-запросов.

Например, если хост недоступен или соединение не удалось установить, запрос учитывается в статистике Errors.

HTTP-ответы с кодами от 200 до 399 считаются успешными.

Ответы с кодами 400 и выше считаются неуспешными и учитываются в Failed.
